**利用者の困りごとを捉え、必要なものを形にして届けるエンジニア。**

鳶職から独学を経て転職し、2024年10月から受託開発に従事しています。
TypeScript・React・Next.jsを中心に、業務システムのフロントエンドの技術選定・設計・実装と開発基盤の整備を担当。
2026年7月からは、案件管理機能の設計・DB設計・フルスタック実装にも担当範囲を広げています。

個人では、YouTubeのBGMチャンネル向け自動化ツールを企画・開発・運営。
100人を超える利用者と直接やり取りし、導入支援から仕様の見直し、利用後の改善まで継続して取り組んでいます。

[詳しい経歴・ポートフォリオ](https://serious-banon-953.notion.site/3527d169a185818a853dfa577c3569da)

## 大切にしていること

- **利用者との対話から仕様を決める** — 要望をそのまま実装するだけでなく、困っていることや運用を確認し、何を作るか・何を優先するかを考える。
- **提供した後も改善する** — 不具合や要望を受け取り、機能だけでなく初期設定・操作案内・移行手順も見直す。
- **AIを活用する開発を仕組みで支える** — Claude Code・Codexを活用し、静的解析・テスト・CI・レビューや開発手順を整備する。

現在は業務・個人開発ともに、AIとの対話で要望を仕様へ具体化し、実装には全面的にAIを活用しています。
ここでの設計・実装は担当範囲を示しています。関係者との認識合わせ、仕様の判断、成果物の確認と継続的な改善を重視しています。

## 仕事で取り組んできたこと

- 建築業向け業務システムをReact／Next.jsへリプレース。52フィールドの業務フォームと4種類の帳票機能を設計・実装。
- 3つの業務アプリのモノレポ移行を提案・推進。在庫管理アプリのフロントエンドを構築し、共通コンポーネントの基盤として展開。
- 行政書士事務所向けシステムをフロントエンドの技術選定から構築し、約1ヶ月で初回リリース。現在は案件管理機能の設計・DB設計・フルスタック実装も担当。
